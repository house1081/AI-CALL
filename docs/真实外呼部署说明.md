# 真实外呼部署说明

## 1. 后端配置 `application.yml`

```yaml
server:
  port: 8081   # 勿与 FS ESL 端口冲突

freeswitch:
  enabled: true
  host: 192.168.60.28
  sip-port: 5060
  esl-port: 8021
  esl-password: ClueCon
  gateway: default
  callback-base-url: http://<Java服务器IP>:8081
  originate-timeout-sec: 60

ai-voice:
  user-silence-before-response-ms: 1000
  turn-based-playback-asr-tail-ms: 800
  playback-barge-in-energy-threshold: 320
```

**商户端/管理端前端** 开发代理需指向 `8081`（`ai-call-web/vite.config.js`、`ai-call-work/vite.config.js`）。

## 2. 对话链路（分段）

外呼固定使用 **VAD 句末 → ASR → LLM → CosyVoice TTS**。

**句末档位优先级：** 任务 `silence_profile` > 总后台「外呼对话链路」DB 配置 > `application.yml`。

**管理端：** `ai-call-web` → 模型配置 → **外呼对话链路**（句末档位、CosyVoice 复刻 ID、接通播报）  
**商户端：** `ai-call-work` → 任务 → **句末档位**（可选覆盖全局）

**依赖：** CosyVoice 复刻 `voice_id` + DashScope Key（TTS/ASR）

## 3. FreeSWITCH 侧

1. **线路表**（管理后台 → 线路管理）：SIP账号 = FS `sofia gateway` 名称。
2. **ESL**：端口/密码与 yml 一致；放行 Java 服务器 IP。
3. **Dialplan**：接通 `POST /api/callback/fs/call-start`，挂断 `POST /api/callback/fs/call-end`。  
   参考：`docs/freeswitch-outbound-dialplan.example.xml`

外呼 originate 使用 `&park()`，Java 通过 ESL 播报与录音（非旧版 `&echo` + HTTP voice-turn）。

## 4. 启动任务流程

1. 总后台：启用线路、配置话术、模型 Key、CosyVoice 复刻 ID。
2. 商户：导入客户、创建任务（可选覆盖句末档位）、启动任务。
3. Java ESL originate → FS 外呼 → 接通 `call-start` → `OutboundDialogLoopService` 对话循环。
4. 整段 TTS 播报 + 本地插嘴检测。
5. 挂断 `call-end` → 结算、录音 URL。

无声音排查见 [语音外呼无声音排查.md](语音外呼无声音排查.md)。

## 5. 自检

```bash
curl http://127.0.0.1:8081/api/callback/fs/health
```

返回 `enabled: true` 且 `eslReachable: true` 表示 ESL 可达。

## 6. 与模拟外呼切换

- `freeswitch.enabled: false` → 模拟拨号。
- `freeswitch.enabled: true` → 真实 ESL 外呼。
